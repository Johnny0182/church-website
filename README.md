# Church Website Template

A modern, responsive church website built with Next.js 16, React, and Tailwind CSS.

## Deploying to Netlify

This project is configured for static export so it can be uploaded directly to Netlify.

- Build command: `npm run build`
- Publish directory: `out`
- Node version: `20`

You can either:

1. Connect the repo in Netlify and keep these settings from `netlify.toml`, or
2. Run `npm run build` locally and drag-and-drop the generated `out/` folder in Netlify Deploys.
